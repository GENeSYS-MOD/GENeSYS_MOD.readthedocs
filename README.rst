GENeSYS-MOD.readthedocs
=======================================

This repository contains the source code for the readthedocs tutorial page (see: https://genesysmod.readthedocs.io/en/latest/).

The readthedocs includes information on installation procedures, some examples, as well as background information on mathematical formulation and structure. 


Links to model repositories
-------------------------------------------------

For the individual model repositories please refer to the following pages:

GENeSYS-MOD.gms (GAMS-based version): https://github.com/GENeSYS-MOD/GENeSYS_MOD.gms 

GENeSYS-MOD.jl (Julia-based version): https://github.com/GENeSYS-MOD/GENeSYSMOD.jl

For verious tools around GENeSYS-MOD, please refer to https://github.com/GENeSYS-MOD/GENeSYS_MOD.tools
